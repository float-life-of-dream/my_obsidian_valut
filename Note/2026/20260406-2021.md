# SQL 实验笔记整理

## 一、表结构与完整性约束的修改 (ALTER)

### 知识点
- `ALTER TABLE` 用于修改已创建的表结构。
- 添加字段：`ALTER TABLE 表名 ADD [COLUMN] 列名 数据类型 [约束] [FIRST|AFTER 列名]`
- 删除字段：`ALTER TABLE 表名 DROP [COLUMN] 列名`
- 添加主键：`ALTER TABLE 表名 ADD PRIMARY KEY (列1, 列2, ...)`
- 删除主键：`ALTER TABLE 表名 DROP PRIMARY KEY`
- 添加外键：`ALTER TABLE 表名 ADD CONSTRAINT 约束名 FOREIGN KEY (列) REFERENCES 父表(列)`
- 删除外键：`ALTER TABLE 表名 DROP FOREIGN KEY 约束名`
- 添加唯一约束：`ALTER TABLE 表名 ADD CONSTRAINT 约束名 UNIQUE (列)`
- 删除唯一约束：`ALTER TABLE 表名 DROP CONSTRAINT 约束名` 或 `DROP INDEX 索引名 ON 表名`
- 添加检查约束：`ALTER TABLE 表名 ADD CONSTRAINT 约束名 CHECK (条件)`
- 删除检查约束：`ALTER TABLE 表名 DROP CONSTRAINT 约束名`

### 代码示例
```sql
-- 删除列
ALTER TABLE orderDetail DROP orderDate;

-- 添加列
ALTER TABLE orderDetail ADD unitPrice NUMERIC(10,2);

-- 添加主键
ALTER TABLE Staff ADD PRIMARY KEY (staffNo);

-- 添加外键
ALTER TABLE Dept ADD CONSTRAINT FK_Dept_mgrStaffNo FOREIGN KEY (mgrStaffNo) REFERENCES Staff(staffNo);
ALTER TABLE Staff ADD CONSTRAINT FK_Staff_dept FOREIGN KEY (dept) REFERENCES Dept(deptNo);

-- 添加检查约束
ALTER TABLE Staff ADD CONSTRAINT CK_Staff_gender CHECK (gender IN ('F','M'));

-- 添加唯一约束
ALTER TABLE Dept ADD CONSTRAINT UN_Dept_deptName UNIQUE (deptName);
```

## 二、单表查询（比较、IN、范围、模糊匹配）

### 知识点
- 基本查询：`SELECT 列 FROM 表 WHERE 条件`
- 比较运算符：`=`, `!=`, `>`, `>=`, `<`, `<=`
- 范围查询：`BETWEEN ... AND ...`
- 集合查询：`IN (值1, 值2, ...)`
- 模糊匹配：`LIKE`（`%` 任意多个字符，`_` 单个字符），`RLIKE` 或 `REGEXP`（正则表达式）
- 排序：`ORDER BY 列 [ASC|DESC]`

### 代码示例
```sql
-- 查询格力空调型号和价格，按价格升序
SELECT model, price FROM aircon WHERE brand = '格力' ORDER BY price;

-- 查询制冷量3500W冷暖空调平均价格
SELECT ROUND(AVG(price)) AS 均价 FROM products WHERE model LIKE 'KFR%35GW%';

-- 查询价格在3000以下、品牌为美的/格力/志高、功率3500W的空调
SELECT manufacturer, model, price FROM products 
WHERE model LIKE '%35GW%' AND manufacturer IN ('美的','格力','志高') AND price <= 3000 
ORDER BY price;
```

## 三、统计函数（COUNT, SUM, AVG, MAX, MIN）

### 知识点
- `COUNT(*)`：总行数；`COUNT(列)`：非NULL行数；`COUNT(DISTINCT 列)`：去重计数
- `SUM(列)`：求和（数值列）
- `AVG(列)`：平均值；可结合 `ROUND()` 取整
- `MAX(列)`、`MIN(列)`：最大值、最小值
- `IF(条件, 真值, 假值)`：条件函数，常用于分组统计中的条件计数或求和

### 代码示例
```sql
-- 统计国庆期间员工数、交易笔数、产品型号数
SELECT COUNT(DISTINCT sid) AS 人数, COUNT(*) AS 笔数, COUNT(DISTINCT pid) AS 型号数
FROM sales_record WHERE sdate BETWEEN '2023-09-29' AND '2023-10-06';

-- 7号员工2023年上半年销售型号数和总台数
SELECT COUNT(DISTINCT pid) AS 型号数, SUM(quantity) AS 总台数
FROM sales_record WHERE sid = 7 AND sdate BETWEEN '2023-01-01' AND '2023-06-30';

-- 制冷量3500W冷暖空调最低价
SELECT MIN(price) AS 最低价 FROM products WHERE model LIKE 'KFR%35GW%';
```

## 四、分组统计与HAVING

### 知识点
- 分组：`GROUP BY 列`
- 分组后筛选：`HAVING 条件`（对聚合结果过滤）
- 常见聚合函数：`COUNT`, `SUM`, `AVG`, `MAX`, `MIN`

### 代码示例
```sql
-- 统计各厂家空调型号数（区分单冷/冷暖）
SELECT manufacturer,
       COUNT(model) AS model_total,
       SUM(model LIKE 'KF%') AS single_total,
       SUM(model LIKE 'KFR%') AS dual_total
FROM products GROUP BY manufacturer ORDER BY model_total DESC;

-- 统计国庆期间员工销售总台数，只显示 >=20 台的结果
SELECT staff.sname, SUM(sales_record.quantity) AS total
FROM sales_record JOIN staff ON sales_record.sid = staff.sid
WHERE sales_record.sdate BETWEEN '2023-09-29' AND '2023-10-06'
GROUP BY staff.sid, staff.sname
HAVING total >= 20
ORDER BY total DESC;
```

## 五、连接查询

### 知识点
- **内连接**：`表1 [INNER] JOIN 表2 ON 连接条件`，只返回匹配的行。
- **左外连接**：`表1 LEFT JOIN 表2 ON 连接条件`，返回左表所有行，右表无匹配则填NULL。
- **右外连接**：`表1 RIGHT JOIN 表2 ON 连接条件`，返回右表所有行。
- **多表连接**：连续使用 `JOIN` 或逗号加 `WHERE` 条件。

### 代码示例
```sql
-- 内连接：查询国庆期间销售明细（型号、厂家、数量、单价、折扣）
SELECT model, manufacturer, quantity, price, discount
FROM sales_record JOIN products ON sales_record.pid = products.pid
WHERE sdate BETWEEN '2023-09-29' AND '2023-10-06'
ORDER BY rid;

-- 左外连接：查询格力空调国庆期间销售明细，没有销售的型号也要显示
SELECT products.model, sales_record.quantity, products.price, sales_record.discount
FROM products LEFT JOIN sales_record ON products.pid = sales_record.pid 
    AND sales_record.sdate BETWEEN '2023-09-29' AND '2023-10-06'
WHERE products.manufacturer = '格力'
ORDER BY products.pid, sales_record.rid;

-- 多表连接：统计各销售人员国庆期间销售总金额
SELECT staff.sname, SUM(sales_record.quantity * products.price * sales_record.discount) AS total
FROM sales_record
JOIN staff ON sales_record.sid = staff.sid
JOIN products ON sales_record.pid = products.pid
WHERE sales_record.sdate BETWEEN '2023-09-29' AND '2023-10-06'
GROUP BY staff.sname
ORDER BY total DESC;
```

## 六、子查询与EXISTS

### 知识点
- **子查询**：嵌套在 `SELECT`、`FROM`、`WHERE` 中的查询。
- **IN / NOT IN**：判断值是否在子查询结果集中。
- **EXISTS / NOT EXISTS**：检查子查询是否有结果行，常与相关子查询配合。
- `SELECT 1` 在 `EXISTS` 中只是占位符，表示“只要存在行即可”。

### 代码示例
```sql
-- 查询郑点没有卖过的厂家
SELECT DISTINCT manufacturer FROM products 
WHERE manufacturer NOT IN (
    SELECT DISTINCT manufacturer FROM products 
    WHERE pid IN (SELECT pid FROM sales_record WHERE sid = (SELECT sid FROM staff WHERE sname = '郑点'))
) ORDER BY manufacturer;

-- 被1-9号员工都卖过的产品（使用 NOT EXISTS 实现除法）
SELECT p.pid, p.model, p.manufacturer, p.price
FROM products p
WHERE NOT EXISTS (
    SELECT 1 FROM staff WHERE sid BETWEEN 1 AND 9
      AND NOT EXISTS (SELECT 1 FROM sales_record s WHERE s.pid = p.pid AND s.sid = staff.sid)
)
ORDER BY p.pid;
```

## 七、限制输出行数 LIMIT

### 知识点
- `LIMIT [偏移量,] 行数`：限制返回的行数。
- 偏移量从0开始，省略则从第1行开始。
- 常用于分页或获取前N条记录。

### 代码示例
```sql
-- 查询制冷量3500W冷暖空调价格最低的三个产品
SELECT manufacturer, model, price
FROM products WHERE model LIKE 'KFR%35GW%'
ORDER BY price LIMIT 3;
```

## 八、综合案例

### 按功率、类型、品牌等条件查询并排序
```sql
-- 查询分体式热泵冷暖双制，制冷量7200W或6000W的落地式空调
SELECT model, manufacturer, price FROM products 
WHERE (model LIKE '%72LW%' OR model LIKE '%60LW%') AND model LIKE 'KFR%'
ORDER BY price ASC;
```

### 统计各厂家3500W空调平均价格（取整）
```sql
SELECT manufacturer AS 厂家, ROUND(AVG(price)) AS 平均价格
FROM products WHERE model LIKE '%35%'
GROUP BY manufacturer ORDER BY manufacturer;
```
