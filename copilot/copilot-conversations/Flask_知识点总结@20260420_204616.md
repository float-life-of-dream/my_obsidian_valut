## Flask 框架核心知识点总结

### 1. **基础概念**
- **微框架**：Flask 是一个轻量级的 Python Web 框架，核心简单但可扩展性强
- **WSGI 兼容**：遵循 WSGI 规范，可与各种 WSGI 服务器配合使用
- **Jinja2 模板引擎**：内置强大的模板系统，支持模板继承、控制结构等

### 2. **核心组件**

#### 路由系统
```python
@app.route('/')
def index():
    return 'Hello World'

@app.route('/user/<username>')
def show_user(username):
    return f'User: {username}'
```

#### 请求对象 (Request)
- `request.method` - HTTP 方法
- `request.form` - POST 表单数据
- `request.args` - GET 查询参数
- `request.files` - 上传的文件
- `request.json` - JSON 数据

#### 响应对象 (Response)
- `return "text"` - 自动包装为 Response
- `return jsonify(data)` - JSON 响应
- `return render_template('template.html')` - 渲染模板
- `return redirect(url_for('index'))` - 重定向

### 3. **模板系统 (Jinja2)**
```jinja2
{# 变量 #}
{{ variable }}

{# 控制结构 #}
{% if condition %}
{% for item in items %}
{% endfor %}
{% endif %}

{# 模板继承 #}
{% extends "base.html" %}
{% block content %}{% endblock %}
```

### 4. **数据库集成**
- **Flask-SQLAlchemy**：ORM 集成
- **Flask-Migrate**：数据库迁移工具
- **配置示例**：
```python
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///app.db'
db = SQLAlchemy(app)
```

### 5. **表单处理**
- **Flask-WTF**：表单验证和 CSRF 保护
- **文件上传**：通过 `request.files` 处理

### 6. **用户认证与会话**
- **Flask-Login**：用户会话管理
- **会话管理**：`session` 对象
- **密码哈希**：Werkzeug 的 `generate_password_hash` 和 `check_password_hash`

### 7. **配置管理**
```python
# 基础配置
app.config['SECRET_KEY'] = 'your-secret-key'
app.config['DEBUG'] = True

# 从文件加载
app.config.from_pyfile('config.py')
app.config.from_object('configmodule.ConfigClass')
```

### 8. **蓝图 (Blueprints)**
```python
# 创建蓝图
admin = Blueprint('admin', __name__)

@admin.route('/')
def admin_index():
    return 'Admin Page'

# 注册蓝图
app.register_blueprint(admin, url_prefix='/admin')
```

### 9. **错误处理**
```python
@app.errorhandler(404)
def page_not_found(error):
    return render_template('404.html'), 404
```

### 10. **扩展生态系统**
- **Flask-RESTful**：构建 REST API
- **Flask-SocketIO**：WebSocket 支持
- **Flask-CORS**：跨域资源共享
- **Flask-Cache**：缓存支持

### 11. **部署相关**
- **开发服务器**：`flask run` 或 `app.run()`
- **生产服务器**：Gunicorn, uWSGI, Waitress
- **静态文件**：`static` 文件夹自动服务
- **环境变量**：通过 `.env` 文件管理配置

### 12. **最佳实践**
1. **应用工厂模式**：使用 `create_app()` 函数创建应用实例
2. **配置分离**：开发、测试、生产环境使用不同配置
3. **错误日志**：合理配置日志记录
4. **安全考虑**：设置 SECRET_KEY，防范 CSRF、XSS 等攻击
5. **代码结构**：合理的项目目录结构

### 13. **常用命令**
```bash
# 运行应用
flask run
flask run --host=0.0.0.0 --port=5000

# 数据库迁移
flask db init
flask db migrate
flask db upgrade

# Shell 环境
flask shell
```

