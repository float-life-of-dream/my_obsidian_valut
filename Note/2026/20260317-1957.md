59.螺旋矩阵[](https://leetcode.cn/problems/spiral-matrix-ii/description/)
思路对矩阵进行模拟
'startx' 记录起始位置
循环次数为边长整除2
记录中间位置
控制遍历长度每遍历一遍，长度向右缩减一位

顺序左闭右开

向右 横坐标递增

向下 纵坐标递增

向左 横坐标递减

向上 纵坐标递减

循环次数-1

```python
        
class Solution:

    def generateMatrix(self, n: int) -> List[List[int]]:

        res = [[0 for _ in range(n)] for _ in range(n)]

        startx ,starty = 0 ,0

        loop = n//2

        count = 1

        offset =  1

        mid = n//2

        while loop > 0:

            i = startx

            j = starty

            for j in range(starty,n-offset):

                res[startx][j] = count

                count+=1

            for i in range(startx,n-offset):

                res[i][n - offset] = count

                count+=1

            for j in range(n-offset,starty,-1):

                res[n-offset][j] = count

                count += 1

            for i in range(n-offset,startx,-1):

                res[i][starty] = count

                count += 1

  

            startx += 1

            starty += 1

            offset += 1

            loop -= 1

        if n%2 == 1:

            res[mid][mid] = countreturn res
```
