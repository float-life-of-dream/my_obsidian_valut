## [#](https://programmercarl.com/%E9%9D%A2%E8%AF%95%E9%A2%9802.07.%E9%93%BE%E8%A1%A8%E7%9B%B8%E4%BA%A4.html#%E6%80%9D%E8%B7%AF)思路

简单来说，就是求两个链表交点节点的**指针**。 这里同学们要注意，交点不是数值相等，而是指针相等。

为了方便举例，假设节点元素数值相等，则节点指针相等。

看如下两个链表，目前curA指向链表A的头结点，curB指向链表B的头结点：

![面试题02.07.链表相交_1](https://file1.kamacoder.com/i/algo/%E9%9D%A2%E8%AF%95%E9%A2%9802.07.%E9%93%BE%E8%A1%A8%E7%9B%B8%E4%BA%A4_1.png)

我们求出两个链表的长度，并求出两个链表长度的差值，然后让curA移动到，和curB 末尾对齐的位置，如图：

![面试题02.07.链表相交_2](https://file1.kamacoder.com/i/algo/%E9%9D%A2%E8%AF%95%E9%A2%9802.07.%E9%93%BE%E8%A1%A8%E7%9B%B8%E4%BA%A4_2.png)

此时我们就可以比较curA和curB是否相同，如果不相同，同时向后移动curA和curB，如果遇到curA == curB，则找到交点。

1. 计算A和B链表的长度
2. 判断A和B的大小
3. 大的一方先遍历，与短的对齐后
4. 同时遍历，检测是否相同
5. 若全部不相同，返回空值
```python
# Definition for singly-linked list.

# class ListNode:

#     def __init__(self, x):

#         self.val = x

#         self.next = None

  

class Solution:

    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> ListNode:

        pointA = headA

        pointB = headB

        lenA = 0

        lenB = 0

        while pointA:

            pointA = pointA.next

            lenA += 1

        while pointB:

            pointB = pointB.next

            lenB += 1

        pointA = headA

        pointB = headB

        if lenA > lenB:

            for i in range(lenA-lenB):

                pointA = pointA.next

                lenA -= 1

        elif lenA < lenB:

            for i in range(lenB-lenA):

                pointB = pointB.next

                lenB -= 1

        while pointA and pointB:

            if pointA == pointB:

                return pointA

            pointA = pointA.next

            pointB = pointB.next

        else:

            return None

```
