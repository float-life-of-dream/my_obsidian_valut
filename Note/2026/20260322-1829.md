```python
class ListNode:

    def __init__(self, val=0, next=None):

        self.val = val

        self.next = next

  

class MyLinkedList:

  

    def __init__(self):

        # 使用虚拟头结点，简化操作

        self.head = ListNode()

        self.size = 0  # 建议维护一个 size 变量，方便边界检查

  

    def get(self, index: int) -> int:

        if index < 0 or index >= self.size:

            return -1

        current = self.head.next

        for _ in range(index):

            current = current.next

        return current.val

  

    def addAtHead(self, val: int) -> None:

        # 在虚拟头结点之后插入

        self.head.next = ListNode(val, self.head.next)

        self.size += 1

  

    def addAtTail(self, val: int) -> None:

        point = self.head

        # 遍历到最后一个节点

        while point.next:

            point = point.next

        # 【修复】将新节点链接到当前尾节点的 next

        point.next = ListNode(val)

        self.size += 1

  

    def addAtIndex(self, index: int, val: int) -> None:

        # 边界检查：如果 index > size，不插入

        if index > self.size:

            return

        # 如果 index < 0，通常视为在头部插入 (根据具体题目要求，这里按标准处理)

        if index < 0:

            index = 0

        point = self.head

        # 找到 index 位置的前一个节点

        for _ in range(index):

            point = point.next

        point.next = ListNode(val, point.next)

        self.size += 1

  

    def deleteAtIndex(self, index: int) -> None:

        # 边界检查：如果 index 无效，不删除

        if index < 0 or index >= self.size:

            return

        point = self.head

        # 找到 index 位置的前一个节点

        for _ in range(index):

            point = point.next

        # 执行删除

        point.next = point.next.next

        self.size -= 1
```

你可以选择使用单链表或者双链表，设计并实现自己的链表。

单链表中的节点应该具备两个属性：`val` 和 `next` 。`val` 是当前节点的值，`next` 是指向下一个节点的指针/引用。

如果是双向链表，则还需要属性 `prev` 以指示链表中的上一个节点。假设链表中的所有节点下标从 **0** 开始。

实现 `MyLinkedList` 类：

- `MyLinkedList()` 初始化 `MyLinkedList` 对象。
- `int get(int index)` 获取链表中下标为 `index` 的节点的值。如果下标无效，则返回 `-1` 。
- `void addAtHead(int val)` 将一个值为 `val` 的节点插入到链表中第一个元素之前。在插入完成后，新节点会成为链表的第一个节点。
- `void addAtTail(int val)` 将一个值为 `val` 的节点追加到链表中作为链表的最后一个元素。
- `void addAtIndex(int index, int val)` 将一个值为 `val` 的节点插入到链表中下标为 `index` 的节点之前。如果 `index` 等于链表的长度，那么该节点会被追加到链表的末尾。如果 `index` 比长度更大，该节点将 **不会插入** 到链表中。
- `void deleteAtIndex(int index)` 如果下标有效，则删除链表中下标为 `index` 的节点。
解释为什么不能直接使用current结点，然后返回head结点好的，根据你提供的 `MyLinkedList` 类实现，我来阐述虚拟头节点和边界条件的使用。

### 虚拟头节点（Dummy Head Node）的使用

在 `MyLinkedList` 类中，`self.head = ListNode()` 就是一个虚拟头节点。

**作用和优点：**

1.  **简化操作逻辑：** 虚拟头节点是一个不存储实际数据，但指向链表第一个实际节点的节点。它的主要目的是为了统一链表操作，特别是对链表头部进行插入和删除操作时，无需进行特殊判断。
    *   **`addAtHead(self, val)`:** 当在头部插入时，可以直接将新节点链接到 `self.head.next`，而不需要检查链表是否为空。
        ```python
        self.head.next = ListNode(val, self.head.next)
        ```
    *   **`deleteAtIndex(self, index)`:** 当删除第一个元素（`index = 0`）时，`point` 会停留在 `self.head`。然后 `point.next = point.next.next` 就能直接删除第一个实际节点，而不需要单独处理 `head` 指针的更新。
        ```python
        # point 最终会是 self.head (当 index 为 0 时)
        point.next = point.next.next
        ```
2.  **避免空链表特殊处理：** 如果没有虚拟头节点，当链表为空时，`head` 指针为 `None`。在进行插入、删除等操作时，需要额外判断 `head` 是否为 `None`，这会增加代码的复杂性。有了虚拟头节点，链表永远不会“空”，`self.head` 始终存在，只是 `self.head.next` 可能为 `None`。
3.  **统一遍历起点：** 在 `get`、`addAtTail`、`addAtIndex` 和 `deleteAtIndex` 方法中，遍历都是从 `self.head` 开始，然后通过 `point = point.next` 移动到实际节点的前一个位置，这使得所有操作的遍历逻辑保持一致。

**如何使用：**

-   初始化时：`self.head = ListNode()`
-   获取实际链表头：`self.head.next`
-   遍历时：从 `self.head` 开始，`point` 总是指向当前节点的前一个节点。

### 边界条件的使用

边界条件检查对于确保链表操作的正确性和鲁棒性至关重要，特别是当用户提供的 `index` 可能无效时。`self.size` 变量在这里起到了关键作用，它维护了链表中实际元素的数量。

1.  **`get(self, index: int) -> int`**
    *   **边界检查：** `if index < 0 or index >= self.size:`
    *   **处理方式：** 如果 `index` 小于 0 或大于等于链表长度，说明 `index` 无效，返回 `-1`。这符合题目要求。
    *   **原因：** 防止访问越界，导致程序崩溃或返回错误数据。

2.  **`addAtHead(self, val: int) -> None`**
    *   **边界检查：** 无需显式检查 `index`，因为这是固定在头部插入。
    *   **处理方式：** 直接在虚拟头节点之后插入新节点。
    *   **原因：** 虚拟头节点的存在使得头部插入操作无需特殊边界处理。

3.  **`addAtTail(self, val: int) -> None`**
    *   **边界检查：** 无需显式检查 `index`，因为这是固定在尾部插入。
    *   **处理方式：** 遍历到链表最后一个节点，然后将新节点链接到其 `next`。
    *   **原因：** 尾部插入操作通常不需要复杂的边界检查，只需找到尾部即可。

4.  **`addAtIndex(self, index: int, val: int) -> None`**
    *   **边界检查 1：** `if index > self.size:`
        *   **处理方式：** 如果 `index` 大于链表长度，根据题目要求，不进行插入，直接 `return`。
        *   **原因：** 防止在链表末尾之后很远的位置插入，这通常被视为无效操作。
    *   **边界检查 2：** `if index < 0:`
        *   **处理方式：** 将 `index` 修正为 `0`，这意味着在头部插入。这是一种常见的处理方式，但具体取决于题目要求。
        *   **原因：** 允许负数 `index` 也能在链表开头插入，增加灵活性。
    *   **`index == self.size` 的情况：** 这种情况下，循环 `for _ in range(index):` 会让 `point` 遍历到链表的最后一个实际节点。然后 `point.next = ListNode(val, point.next)` 实际上就是将新节点插入到最后一个节点的后面，即追加到末尾，符合题目中“如果 `index` 等于链表的长度，那么该节点会被追加到链表的末尾”的要求。

5.  **`deleteAtIndex(self, index: int) -> None`**
    *   **边界检查：** `if index < 0 or index >= self.size:`
    *   **处理方式：** 如果 `index` 无效（小于 0 或大于等于链表长度），不进行删除，直接 `return`。
    *   **原因：** 防止访问越界，删除不存在的节点，或导致程序崩溃。

通过这些虚拟头节点和边界条件的使用，你的 `MyLinkedList` 类能够更健壮、更简洁地处理各种链表操作。
