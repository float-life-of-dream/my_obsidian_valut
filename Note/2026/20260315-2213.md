# 20260315-2203
题目i[](https://leetcode.cn/problems/minimum-window-substring/description/?envType=study-plan-v2&envId=top-100-likeid)
思路
	通过设置哈希表
	向右遍历
	首先判断t中字母是否全部包含在s的子串
	之后对子串进行缩小
	移除左边的字符
	如果移除后不满足要求 ，计数器建议
	左边界逼近
```python
class Solution:

    def minWindow(self, s: str, t: str) -> str:

        lens = len(s)

        lent = len(t)

        if lens < lent or lens == lent and s != t:

            return ""

        s_dict = {}

        t_dict = {}

        cnt, left = 0, 0

        for char in t:

            t_dict[char] = t_dict.get(char, 0) + 1

        ans = ""

        for right, char in enumerate(s):

            s_dict[char] = s_dict.get(char, 0) + 1

            if char in t_dict and s_dict[char] == t_dict[char]:

                cnt += 1

            while cnt == len(t_dict):

                # 更新最小窗口

                if not ans or right - left + 1 < len(ans):

                    ans = s[left:right+1]

  

                # 收缩窗口：移除左边界字符

                left_char = s[left]

                s_dict[left_char] -= 1

  

                # 如果移除后不满足 t 的要求，计数器减少

                if left_char in t_dict and s_dict[left_char] < t_dict[left_char]:

                    cnt -= 1

  

                left += 1

        return ans
```
